Xteon Pro AV Complete Field Manual

Step-by-step operational workflows for Front of House (FOH) engineers, video directors, and stage technicians. Learn how to master every tool included in the v1.3.1 suite.

01

Quick Start & Keyboard Shortcuts

Xteon operates as an offline, high-speed desktop CAD workstation. Familiarize yourself with the core navigational bindings:

Pan Canvas Space + Drag or Middle Mouse
Zoom In / Out Scroll Wheel / Pinch
Save Project Ctrl + S (Cmd + S on Mac)
Delete Node / Cable Delete or Backspace
02

CAD Canvas, Device Nodes & Cable Routing

Step 1: Adding Hardware Nodes

Click the Add Device dropdown in the top toolbar to instantiate hardware nodes. You can select from:

  • Sources: Media Servers (Disguise, Hippotizer, Resolume), Laptops (HDMI/Type-C), PTZ Cameras, SDI Routers.
  • Processors: LED Processors (NovaStar MCTRL4K, Brompton Tessera SX40/S8), Video Switchers (Barco E2, Blackmagic ATEM), Decimator MD-HX Cross Converters.
  • Sinks: LED Video Walls, Projectors, Commercial Smart TVs, Confidence Monitors (DSM).

Step 2: Drawing Cable Connections

Hover over any Output Port Handle (right side of a device node), click and drag a bezier connection line to an Input Port Handle on a downstream destination node.

Step 3: Real-Time Signal Validation

Click on any drawn cable to inspect its parameters in the right-hand inspector panel. Xteon instantly calculates:

  • Calculated Bandwidth (Gbps): Evaluates resolution, frame rate (e.g. 59.94Hz), and color bit-depth.
  • Distance Limits: Flags a CRITICAL WARNING if you exceed copper limits (e.g., HDMI 2.0 copper over 5 meters) and suggests Fiber AOC or HDBaseT conversion.
03

Virtual Distribution Amplifiers & Splitter Branching

In live events, a single output from a video switcher often feeds an array of distributed TVs and confidence monitors via a 1x2, 1x4, or 1x8 Distribution Amplifier (DA).

How to Configure a Splitter Branch:
  1. Add a Distribution Amp (Splitter) node to the canvas.
  2. In the node inspector, choose your multiplier (e.g., 1x4 or 1x8).
  3. Connect your upstream source into the input port.
  4. Connect the output ports to your stage TVs and confidence monitors.
  5. Assign unique stage zone names (e.g., "Stage Left Green Room", "FOH VIP Lounge") to each downstream branch.
04

Physical Display Discovery & Live Convergence

When operating in Live Map Mode, Xteon queries the operating system kernel to detect real physical displays plugged into your GPU outputs.

  • Auto-Reconciliation: Matches planned canvas nodes against physically plugged displays based on resolution, refresh rate, and display name.
  • Mirroring Detection: Automatically flags accidental display mirroring (when an external projector shares 0,0 origin coordinates with the host laptop).
  • Flash Display: Click the flash icon to flash a full-screen identification pattern on an external screen, confirming physical cable identity on stage.
05

Live Camera Ingest & Multi-View Monitoring

Open the Camera Ingest Drawer from the top toolbar to monitor live stage video feeds inside Xteon:

  • Automatic Device Classification: Automatically sorts feeds into External Pro (HDMI/SDI capture cards like Elgato Cam Link, Blackmagic DeckLink), Wireless Stage Cams (Iriun 4K phone cams), and Internal Webcams.
  • Privacy Standby Mode: Built-in webcams and virtual drivers remain in standby with zero sensor activation until explicitly engaged.
  • Multi-View Grid: Monitor live frame previews, freeze incoming frames for inspection, and customize stage camera labels.
06

Industrial Cable Label Printer Exporter (Brother & Brady)

Eliminate hand-written tape labels during load-in. Export formatted CSV label data directly into industrial label software:

Step-by-Step Label Printing Workflow:
  1. In the top navbar, click File → Export Outputs → Cable Labels (P-Touch/Brady CSV).
  2. A standardized RFC 4180 CSV file is downloaded to your machine.
  3. Open Brother P-Touch Editor or Brady Workstation.
  4. Choose File → Database → Connect and select the downloaded CSV.
  5. Map the CSV fields: Cable ID, Source Device, Target Device, Wire Color, and Length to your wrap-around cable label template.
  6. Print your entire show run-list in seconds!
07

Printable 11x17 Tabloid & A3 Vector Blueprint Schematic

Provide stage crew and Front-of-House leads with a crisp, physical vector schematic:

  • Click File → Export Outputs → Print FOH Blueprint (Tabloid/A3).
  • A full-screen print preview modal appears containing:
    • • Scalable vector SVG schematic diagram
    • • Bill of Materials (BOM) hardware inventory table
    • • Cable pull run-list with lengths and connector standards
    • • Embedded ANSI E1.21 entertainment rigging safety disclaimer
  • Click Print / Save as PDF and select 11x17" Tabloid or A3 paper size in your print dialog.
08

Acoustic Audio-to-Video Delay Calculator

Align live Front-of-House sound waves with video screen photons:

Operating Procedure:
  1. Click the Audio Delay (⏱️) button on the primary toolbar.
  2. Input the Ambient Venue Temperature in °C or °F (sound travels faster in warmer air).
  3. Input the FOH / Audience Distance from the main PA speakers (in meters or feet).
  4. Set the Video Processing Latency (typically 2 to 3 frames of switcher and processor delay).
  5. Select your project frame rate (e.g., 59.94 fps or 60 fps).
  6. Read the Recommended Console Matrix Delay (ms) and enter that exact value into your audio console's matrix outputs.
09

Show Shields, Anti-Dimming & Flight Recorder

Access these mission-critical guards inside the Settings Modal:

Caffeine Keep-Awake Shield:

Prevents the operating system from entering sleep mode or activating screen savers during live rehearsals and shows.

Anti-Dimming Heartbeat:

Emits an imperceptible 1-pixel micro-toggle beacon every 20 seconds to defeat Samsung and LG Eco Sensors on static keynote slides.

Audio Level Guard:

Monitors system WASAPI loopback audio and immediately warns you if an active presenter microphone drops silent.

Blackbox Flight Recorder:

Maintains a timestamped audit trail of all display connects, disconnects, resolution shifts, and audio anomalies.

10

Hardware Protocols: Companion, OSC, ProPresenter & OBS

Connect Xteon to your venue's hardware control surfaces in Settings → Integrations:

  • Bitfocus Companion & Stream Deck (Port 8765): Connect your Stream Deck via WebSocket to trigger blackout modes, recall layout presets, and view live display tallies on LCD keys.
  • Open Sound Control (OSC Port 8000 UDP): Listen for incoming cue strings from QLab, Resolume Arena, or lighting consoles (grandMA3).
  • ProPresenter 7 Sync (Port 1025 REST): Automatically detect active Stage Screens and Audience Displays configured inside ProPresenter.
  • OBS Studio & vMix (Ports 4455 / 8099): Bridge virtual camera sources and verify program feed health.
11

Project File Management & Industry Starter Templates

Save, reload, and share your work using standard local files:

  • Save Project (Ctrl+S): Saves your schematic canvas, node positions, port custom names, and wire lengths into a portable .xteon JSON project file.
  • Starter Templates: Click File → Industry Templates to load pre-engineered reference topologies:
    • • Corporate Keynote & Breakout Rig (Laptop ingest, switcher, primary LED wall & DSM confidence monitor)
    • • House of Worship Multi-Screen Setup (ProPresenter, stage confidence monitors, broadcast livestream branch)
    • • Arena Concert & Festival Video Rig (Disguise media server, 12G-SDI routing, Brompton LED wall processing)
