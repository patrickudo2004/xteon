Legal Compliance & Data Governance

Privacy Policy

Effective Date: October 12, 2026 • Version 1.3

1. Local-First Architecture (Zero Surveillance Guarantee)

Xteon is engineered as a strictly local-first desktop application and pre-production workspace. We believe that live event setups, production schematics, and media configurations are proprietary intellectual property belonging solely to the user.

  • Zero Cloud Telemetry: Xteon does not transmit analytics, user metrics, device telemetry, or canvas schematics to remote servers.
  • No User Tracking: There are no advertising identifiers, third-party cookies, or background telemetry trackers embedded in the software.
  • Local Storage: All project files (.xteon), preferences, and hardware aliases are saved strictly on your local device.

2. Camera, Audio & Screen Permissions

To provide display intelligence and camera management, Xteon requests OS-level hardware permissions (Camera, Microphone, and Screen Capture):

  • Video Camera Feeds: Video from connected HDMI capture cards, NDI sources, and webcams is decoded exclusively in local RAM to render preview thumbnails. No video is recorded, saved to disk, or broadcast over the internet.
  • Audio Routing & VU Levels: Audio device querying is used solely to compute peak VU meters and prevent HDMI audio routing hijacks. Audio is never recorded, buffered, or transmitted.
  • Screen Capture Thumbnails: Low-frame-rate display previews are captured locally using GPU hardware acceleration. They never leave the host workstation.

3. Mobile Companion Local LAN Security

When the Mobile Companion feature is engaged:

  • Communication occurs strictly over your private local area network (LAN) on port 8765.
  • Access requires entering a randomized 6-digit cryptographic PIN displayed on the FOH workstation.
  • The companion server does not connect to external cloud relays or internet proxies.

4. Software Updates

When you click "Updates" or when the in-app updater checks for releases, the application queries the public GitHub Releases API (https://github.com/patrickudo2004/xteon) to read latest.json. This request contains standard HTTP headers (IP address and User-Agent) processed by GitHub according to GitHub's Privacy Policy. No project or personal data is transmitted.
