1. Consumer & Commercial Smart TV Calibration for Live Events

Prevent unexpected sleep timeouts, distorted aspect ratios, and 80ms+ motion smoothing latency.

Samsung Display

Tizen / Crystal
  • 1. Force PC Mode: Sources → Edit Device Type → Select "PC". Unlocks 4:4:4 chroma subsampling and completely bypasses heavy image processing.
  • 2. Disable Eco Sensor: General → Eco Solution → Turn OFF Ambient Light Detection, Eco Sensor, and Auto Power Off.
  • 3. Eliminate Overscan: Picture → Picture Size Settings → Set to "Custom" and enable Fit to Screen: ON.

LG Commercial & OLED

webOS
  • 1. Relabel Input to PC: Home Dashboard → Edit Input → Change HDMI icon to "PC". Drops input lag from ~85ms down to <12ms.
  • 2. Enable Just Scan: Picture → Aspect Ratio → Set Just Scan = ON (never Auto). Guarantees pixel-perfect 1:1 computer desktop mapping.
  • 3. Kill Energy Saving: General → Energy Saving → Turn OFF to prevent stage lighting from triggering dimming.

Sony BRAVIA Pro

Google TV
  • 1. Picture Mode "Graphics": Picture Settings → Mode → Select "Graphics" or "Game" for 0ms frame interpolation delay.
  • 2. Screen Area Full Pixel: Display & Sound → Screen → Wide Mode = "Full", Display Area = "Full Pixel" (or +1).
  • 3. Disable Idle Standby: Power & Energy → Turn OFF "Idle TV Standby" and "Auto Shut-off after inactivity".

2. Decimator MD-HX Cross Converter DIP Switch Matrix

The indispensable field converter: HDMI ⇄ SDI, Frame Rate Conversion & Resolution Scaling.

Switch Position Switch UP (0) Switch DOWN (1) Pro AV Live Production Use Case
SW 1 (HDMI Out Src) Scaler Output Direct SDI In (Loop) Down for zero-latency SDI-to-HDMI confidence monitor loop
SW 2 (SDI Out 1..4) Scaler Output Direct HDMI In Down for immediate HDMI-to-SDI conversion without scaling
SW 3 (Scaler In Src) SDI Input HDMI Input Up = Scale incoming SDI; Down = Scale incoming HDMI (Laptop)
SW 4 (Scaler Ref) Free Run (Internal) Source Lock / Ext Genlock Set Down to lock frame rate to incoming source without frame drop
Pro Tip: Hold down both rotary buttons for 3 seconds to restore MD-HX factory defaults when on-screen menu is corrupted. Status LED Green = Valid Signal Lock
